# UI 치트시트

| 문제                                  | 해결                                                     |
| ------------------------------------- | -------------------------------------------------------- |
| 오래된 시각이 "340 days ago"로 보임   | 일주일이 지나면 절대 날짜로 바꿈                         |
| 숫자가 바뀔 때 흔들림                 | `font-variant-numeric: tabular-nums`                     |
| 큰 제목이 어색해 보임                 | `-0.02em`처럼 자간을 좁힘                                |
| 본문이 어색해 보임                    | `max-width: 65ch`로 한 줄을 약 65자로 제한               |
| 버튼이 반응하지 않는 느낌             | `:active`에 `transform: scale(0.97)`                     |
| 아바타가 타원으로 찌그러짐            | 아바타에 `flex-shrink: 0`                                |
| 그라디언트 페이드에 경계가 보임       | 이징 그라디언트 사용: 이징 곡선을 따라 색 정지점을 더함  |
| 트랜지션이 여전히 어색함              | 트랜지션 동안 `filter: blur(2px)`를 더함                 |
| 드롭다운이 굼뜸                       | 300ms 미만의 `ease-out`. `ease-in`은 절대 쓰지 않음      |
| 팝오버가 엉뚱한 곳에서 커짐           | `transform-origin`을 트리거에 둠(모달은 가운데 유지)     |
| 개수가 "1 members"로 나옴             | `Intl.PluralRules`로 복수형 처리                         |
