ponytail gain 점수표를 보여 준다. 일회성이며 아무것도 바꾸지 않는다. 모드를 바꾸거나, 플래그 파일을 쓰거나, 무엇이든 저장하지 마라. 공개된 Ponytail 5 에이전트 벤치마크 결과를 일반 ASCII 막대로 그린다. 벤치마크는 실제 FastAPI + React 저장소의 작업에 버그 수정, 보안과 개인정보 사례, 작은 앱을 더한 작업 39개를 Opus 5.5로 작업마다 5번씩 돌려 스킬 없는 같은 에이전트와 비교했고, 작업별 중앙값의 기하 평균을 냈다. 출처는 benchmarks/results/2026-10-07-agentic.md와 README다. 스킬 없는 기준(100%) 대비 ponytail의 비율로 나타낸다. 코드 줄 수 47%(53% 감소). 출력 토큰 55%(45% 감소). 비용 74%(26% 감소). 시간 59%(41% 감소). 숨은 검사 통과 97%(스킬 없음 96%. 작업 중 18개에 정확성과 안전성을 보는 숨은 검사가 있다). 로직에 필요한 곳의 테스트 98%(스킬 없음 68%). 막대 길이는 비율을 보여 주고, 이름표에는 정확한 수치를 적는다. 이 수치는 이 저장소가 아니라 벤치마크의 평균이다. 저장소별 절감 수치는 절대 출력하지 마라. 만들지 않은 버전은 실제로 작성된 적이 없으므로, 실제 저장소에는 빼서 비교할 진짜 기준값이 없다. 저장소별 실제 수치가 필요하면 /ponytail-debt(개수를 센 단순화 부채 목록)와 /ponytail-audit(아직 줄일 수 있는 것)를 안내한다. 보고만 한다.
