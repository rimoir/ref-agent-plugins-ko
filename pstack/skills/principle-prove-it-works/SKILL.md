# 동작을 증명하라(Prove It Works)

모든 출력은 실물을 직접 확인해 검증한다. 기능을 돌려 보고, 실제 값을 읽고, diff를 살핀다. 대리 지표(파일 mtime, 자가 보고, 캐시된 출력, "컴파일은 된다")는 치지 않는다. 확인이 실패하면 시스템을 의심하기 전에 관찰 방법부터 의심한다.

가능하면 확인을 스크립트로 만든다. 비교를 다시 돌리는 결정론적 스크립트가 한 번 눈으로 보는 것보다 낫다. 그 출력은 사람이 볼 수 있는 곳에 두고, 나중에 기록을 감사할 수 있어야 할 때만 커밋한다.
