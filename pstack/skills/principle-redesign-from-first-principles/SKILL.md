# 첫 원칙에서 다시 설계한다

변경을 통합할 때 기존 설계에 덧대지 않는다. 그 요구 사항이 처음부터 있었던 것처럼 다시 설계한다.

- 영향받는 파일을 모두 읽고 현재 설계를 이해한다
- 묻는다. "이 새 요구 사항을 안고 처음부터 쓴다면 무엇을 만들까?"
- 변경을 모든 참조에 퍼뜨린다. 타입, 문서, 예시, 근거 섹션
- 다시 설계할 전체를 생각한 다음, 점진적으로 전달한다

기존 설계에 변경을 통합하면서 선택지의 가치(option value)를 지키는 방법이다.
