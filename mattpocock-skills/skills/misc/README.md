# Misc

가지고는 있지만 거의 쓰지 않는 도구다. 정식 버킷(promoted, 플러그인에 포함되고 문서 페이지가 있는 engineering/과 productivity/)이 아니어서 플러그인에 들어가지 않는다.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: 위험한 git 명령(push, reset --hard, clean 등)을 실행 전에 막는 Claude Code 훅을 설정한다.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: 테스트 파일의 `as` 타입 단언을 @total-typescript/shoehorn으로 옮긴다.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: 섹션, 문제, 해답, 설명 자료를 갖춘 연습 문제 디렉터리 구조를 만든다.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: lint-staged, Prettier, 타입 검사, 테스트를 실행하는 Husky pre-commit 훅을 설정한다.
