# 기초적 사고

로직을 쓰기 전에 데이터 형태를 제대로 잡는다. 핵심 타입을 일찍 정의하고, 모든 접근 패턴을 추적하고, 주된 경로에 맞는 구조를 고른다. 모든 줄이 아니라 구조를 DRY하게 만든다.

주체들 사이에 상태를 공유하기 전에, 다른 주체가 그것을 동시에 수정하면 어떻게 되는지 묻는다. 답이 "아무 일도 없다"가 아니면 격리한다.

뼈대가 먼저다. 이후의 모든 단계에 도움이 되는 것(CI, 테스트, 공유 타입)은 죽은 코드를 지운 뒤 가장 먼저 한다. 커밋은 작고 목적이 하나여야 한다.
