description: 현재 대화를 인계 문서로 압축해 다른 에이전트가 이어서 작업하게 한다.
argument-hint: "다음 세션에서는 어떤 작업을 할 건가요?"
disable-model-invocation: true
---

새 에이전트가 작업을 이어 갈 수 있게 현재 대화를 요약한 인계 문서를 쓴다. 문서는 현재 작업 공간이 아니라 사용자 OS의 임시 디렉터리에 저장한다.

문서에 "추천 스킬" 섹션을 넣고, 다음 에이전트가 Skill 도구로 호출해야 할 스킬을 적는다.

다른 산출물(스펙, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용은 다시 적지 않는다. 대신 경로나 URL로 가리킨다.

API 키, 비밀번호, 개인 식별 정보 같은 민감한 정보는 모두 지운다.

사용자가 인자를 넘겼다면 다음 세션에서 집중할 작업의 설명으로 보고, 그에 맞춰 문서를 작성한다.
