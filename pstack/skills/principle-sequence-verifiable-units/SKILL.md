# 검증 가능한 단위로 작업 나누기(Sequence work into verifiable units)

작업을 각각 확인할 수 있는 상태로 끝나는 작은 단위로 배열하고, 현재 단위가 green이 되기 전에는 나아가지 않는다.

일괄 수정, 마이그레이션, 비슷한 수정의 연속에서 각 단위는 괄호 하나다. 정상으로 알려진 상태, 변경 하나, 확인 실행, 그다음 진행이다. 도구가 수정을 하더라도 단위별 확인은 돌린다.

작업을 증명하는 순서로 전달한다. 실패하는 테스트가 먼저, 그다음 수정. 형태를 바꾸기 전에 빼기. 처치 전에 기준선. 각 커밋은 홀로 착지한다.
