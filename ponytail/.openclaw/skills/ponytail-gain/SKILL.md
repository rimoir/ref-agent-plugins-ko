# Ponytail Gain

호출되면 이 점수표를 보여 준다. 일회성이다. 모드를 바꾸거나, 플래그 파일을
쓰거나, 무엇이든 저장하지 마라.

수치는 공개된 Ponytail 5 에이전트 벤치마크 결과다. 헤드리스 Claude Code(Opus 5.5,
기본 effort)가 작업 39개(실제 FastAPI + React 저장소의 기능 티켓, 버그 수정, 보안과
개인정보 사례, 작은 앱)를 작업마다 5번씩 처리했고, 스킬 없는 같은 에이전트와 비교했다.
작업 중 18개에는 정확성과 안전성을 보는 숨은 검사가 있다. 각 수치는 작업별 중앙값의
기하 평균이다. 현재 저장소에서 계산한 값이 아니라 측정한 값이다.
출처는 `benchmarks/results/2026-10-07-agentic.md`와 README다.

## 점수표

일반 ASCII 막대로 그린다. 막대 길이는 스킬 없는 기준 대비
ponytail의 비율을 보여 주고, 이름표에는 정확한 수치를 적는다.

```
  ponytail gain           벤치마크 · 작업 39개 × 5회 · Opus 5.5

  스킬 없음       ████████████████████  100%
  코드 줄 수      █████████···········   47%   ▼ 53%
  출력 토큰       ███████████·········   55%   ▼ 45%
  비용            ███████████████·····   74%   ▼ 26%
  시간            ████████████········   59%   ▼ 41%
  숨은 검사 통과   97%  (스킬 없음 96%)
  로직에 필요한 곳의 테스트   98%  (스킬 없음 68%)

  이 저장소:  /ponytail-debt  (미뤄 둔 단순화)
              /ponytail-audit (아직 줄일 수 있는 것)
```

## 정직하게 보여 줄 범위

이 수치는 이 저장소가 아니라 벤치마크의 평균이다. 저장소별 절감 수치("여기서
X줄/토큰을 절약했다")는 절대 출력하지 마라. 만들지 않은 버전은 실제로 작성된 적이
없으므로, 실제 저장소에는 빼서 비교할 진짜 기준값이 없다. 저장소별로 실제 수치를
내는 것은 `/ponytail-debt`(개수를 센 부채 목록)뿐이다. 이 점수표는 수치를
지어내지 않고 그 명령을 안내한다.

## 범위

일회성 표시다. 아무것도 수정하지 않고 모드도 바꾸지 않는다.
"stop ponytail" 또는 "normal mode"라고 하면 원래대로 돌아간다.
