# 타입 시스템 규율

컴파일러가 불가능한 상태, 어긋난 원시 타입, 처리하지 않은 변형을 거부하게 만든다.

- **의미 있는 원시 타입에 브랜드를 붙인다.** 함수 인자 두 개가 같은 원시 타입이지만 뜻이 다르면 각각 고유한 타입을 준다. 생성할 때 한 번 검증한다.
- **외부 데이터는 파싱하기 전까지 타입이 없다.** JSON, RPC 페이로드, CLI 인자, 설정, 환경변수, 데이터베이스 행은 경계에서 타입 있는 모델을 돌려주는 파싱 함수를 거친다.
- **권위 있는 스키마에서 타입을 유도한다.** 스키마 파일이 모양을 소유하면, 나란한 타입을 손으로 만들지 말고 거기서 유도한다.

TypeScript 문법은 **typescript-best-practices** 스킬을 본다.
