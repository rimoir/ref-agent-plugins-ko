# 강한 의존성이 있는 스킬에만 `/setup-matt-pocock-skills` 안내를 명시한다

엔지니어링 스킬은 `/setup-matt-pocock-skills`가 만들어 두는 저장소별 설정(이슈 트래커, 분류 라벨 어휘, 도메인 문서 구성)에 기댄다. 어떤 스킬은 이 설정 없이는 제대로 동작할 수 없다. 특정 이슈 트래커에 게시하거나 특정 라벨 문자열을 붙여야 하기 때문이다. 다른 스킬은 결과를 더 정확하게 만드는 데(어휘, ADR(아키텍처 결정 기록) 참고)만 이 설정을 쓰고, 설정이 없어도 품질이 조금 떨어질 뿐 계속 동작한다.

그래서 스킬을 **강한 의존성** 스킬과 **약한 의존성** 스킬로 나눈다.

- **강한 의존성** (`to-tickets`, `to-spec`, `triage`): 한 줄 안내를 명시한다. _"…는 이미 제공되었어야 한다. 제공되지 않았다면 `/setup-matt-pocock-skills`를 실행한다."_ 대응 정보가 없으면 결과가 조금 흐릿한 정도가 아니라 틀린다.
- **약한 의존성** (`diagnose`, `tdd`, `improve-codebase-architecture`): "프로젝트의 도메인 용어집"과 "지금 작업하는 영역의 ADR"을 막연한 문장으로만 언급한다. 문서가 없어도 스킬은 동작하고, 결과가 덜 정확할 뿐이다.

이렇게 나누면 약한 의존성 스킬이 쓰는 토큰이 적게 유지되고, 설정 안내가 꼭 필요하지 않은 곳에 이유 없이 따라 들어가는 일을 막는다.
