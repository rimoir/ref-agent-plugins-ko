# 토큰 절약

모델의 주의력은 구현과 판단에 쓴다. 반복되고 결정적인 검증은 명령으로 옮기고, 오케스트레이션(총괄 에이전트가 리프를 여러 에이전트에 나눠 맡기고 검증과 통합을 하는 방식) 컨텍스트는 좁게 유지한다.

## 강제 비용을 낮게 유지하기

- **실행 가능한 검사를 쓴다.** 외부 명령 실행 자체에는 모델 추론이 필요하지 않다. 그래도 에이전트는 명령, 돌려받은 출력, 실패 해석, 증거 검토에 컨텍스트를 쓴다.
- **증거 크기를 제한한다.** 확정된 실행 환경 정보와 자동 출력 요약 해시를 저장하고, 성공한 원본 출력이나 빌드 로그 전체는 절대 저장하지 않는다.
- **Stop 훅은 검사만 하게 둔다.** 훅 자체는 모델을 호출하지 않는다. 하지만 차단하면 에이전트가 작업을 이어 가고 이때 모델 작업이 소비되므로, 진행 없이 여섯 번 차단되면 멈춤을 허용하는 진행 안전장치를 유지하고 차단할 때마다 바로 행동할 수 있는 내용을 준다.
- **기본으로 검사를 순차 실행한다.** 실제 경과 시간을 줄이는 이득이 실패 원인을 찾기 어려워지는 손해보다 클 때만, 서로 독립된 검사에 한해 `--jobs`를 올린다.

## 컨텍스트를 좁게 유지하기

- 리프(leaf, 트리 맨 아래의 작업 단위)에는 공유 계약과 그 리프의 게이트 파일만 준다(게이트는 완료로 인정하려면 충족해야 하는 조건 한 항목이다). 총괄 에이전트의 실행 기록이나 관련 없는 리프의 출력은 주지 않는다.
- `SKILL.md`에는 핵심 워크플로만 둔다. 방법, 게이트, 오케스트레이션, 병렬 참고 문서는 선택한 모드에 필요할 때만 불러온다.
- 이벤트는 `status.log`에 덧붙인다. 한 줄로 이벤트를 기록할 수 있는데 큰 계획을 되풀이해 다시 만들지 않는다.
- 실패 로그는 로컬에 두고, 수동 보고에 필요할 때 민감하지 않으면서 판단을 좌우하는 사실만 요약한다. 자동 성공 증거에는 이미 다이제스트와 바이트 수가 들어 있다.

## 없는 호스트 제어를 지어내지 않고 리프의 추론 필요 정도 표시하기

추론 등급(`Tier`)은 실행 리프에 붙이는 계획 메타데이터다. 모델 이름도 아니고 특정 모델로 보낸다는 보장도 아니다.

- 리프가 만드는 결과물 자체에 설계, 보안, 호환성 추론이나 영향이 큰 수동 검토, 기계적이지 않은 검증이 필요하면 `judgment`를 쓴다.
- 변환 패턴과 완료 판정 게이트가 이미 정해져 있을 때만 `mechanical`을 쓴다.

호스트가 문서로 공개한 모델 제어나 추론 제어를 제공하면, 총괄 에이전트는 실행 시작할 때 그 호스트 전용 제어로 추론 등급을 대응시켜도 된다. 그런 제어가 없으면 추론 등급을 작업 지시와 검토 요구 사항으로만 남기고, 특정 모델이나 추론 수준을 골랐다고 주장하지 않는다.

총괄 에이전트와 중간 노드(branch)의 업무에는 리프 추론 등급이 없다. 계약과 아키텍처 작업, 배정(dispatch) 결정, 부모 재검증, 중간 노드 통합, 최종 주장 점검은 모든 실행 리프가 mechanical이어도 판단 업무로 남는다.

## 잘못된 절약 피하기

승인, 음성 대조(검사가 걸러 내야 하는 입력을 넣어 검사가 실제로 실패하는지 확인하는 것), 부모 재검증, 통합 게이트를 건너뛰어 시간을 아끼지 않는다. 이 검사들이 있는 까닭은, 빨리 끝났지만 실제로는 완료되지 않은 결과가 곧바로 드러나는 실패보다 비용이 더 크기 때문이다.

집중한 세션 하나로 깔끔하게 구현하고 검증할 수 있는 작업은 오케스트레이션하지 않는다. 반대로, 독립된 리프와 계약이 분명한데도 서브에이전트 오버헤드를 피하려고 구축 작업 전체를 한 컨텍스트에 두지 않는다.

## 측정 주장

이전 unlazy 문서는 과거에 탐색 목적으로 한 비교 실험(6회 실행)에서 나온 정확한 토큰 비율과 작업량 비율을 제시했다. 이 저장소에는 원본 프롬프트, 실행 추적, 출력, 채점 기록이 없으므로 여기서는 그 숫자를 재현할 수 없다. 그 숫자를 제품 보장으로 쓰지 않는다. 앞으로 재현 가능한 재실행을 할 때의 절차는 [../research/validation-protocol.md](../research/validation-protocol.md)에 있다.
