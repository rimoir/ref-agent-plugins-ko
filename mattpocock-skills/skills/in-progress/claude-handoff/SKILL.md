현재 대화의 인계 요약을 써서 새 에이전트가 작업을 이어 갈 수 있게 한다. 요약을 저장하지 말고, 요약을 프롬프트로 넣은 백그라운드 에이전트를 실행한다: `claude --bg --name "<descriptive name>" "<handoff summary>"`. 새 에이전트는 현재 작업 디렉터리에서 시작하고 명령은 바로 반환된다. 사용자는 `claude agents`로 이 에이전트를 관리한다.

항상 `-n`/`--name`에 무슨 작업인지 알 수 있는 이름을 넘긴다(예: `--name "Fix login bug"`). 이 이름은 작업 목록, 세션 선택기, 터미널 제목에 표시된다.

요약에 "추천 스킬" 섹션을 넣어, 다음 에이전트가 Skill 도구로 어떤 스킬을 호출해야 하는지 적는다.

다른 산출물(스펙, 계획, ADR(아키텍처 결정 기록), 이슈, 커밋, diff)에 이미 담긴 내용은 되풀이하지 않는다. 대신 경로나 URL로 가리킨다.

요약이 곧 에이전트의 프롬프트가 되므로 API 키, 비밀번호, 개인 식별 정보 같은 민감한 정보는 지운다.

사용자가 인자를 넘겼다면 다음 세션이 집중할 일을 설명한 것으로 보고 요약을 거기에 맞춘다.
