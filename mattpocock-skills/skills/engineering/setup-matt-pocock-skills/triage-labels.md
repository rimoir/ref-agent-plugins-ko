# 분류 라벨

스킬은 표준 분류(triage) 역할로 이슈 상태를 말한다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 연결한다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 의미                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너가 이 이슈를 검토해야 함  |
| `needs-info`               | `needs-info`         | 보고자가 정보를 더 주기를 기다리는 중 |
| `ready-for-agent`          | `ready-for-agent`    | 내용이 모두 정해져 AFK(사람 없이 에이전트 혼자 진행) 에이전트가 바로 작업할 수 있음  |
| `ready-for-human`          | `ready-for-human`    | 사람이 직접 구현해야 함            |
| `wontfix`                  | `wontfix`            | 처리하지 않음                     |

스킬이 역할을 언급하면(예: "AFK 에이전트가 바로 작업할 수 있다는 분류 라벨을 붙인다") 이 표에서 그 역할에 해당하는 라벨 문자열을 쓴다.

실제로 쓰는 라벨 이름에 맞게 "우리 트래커의 라벨" 열을 고친다.
